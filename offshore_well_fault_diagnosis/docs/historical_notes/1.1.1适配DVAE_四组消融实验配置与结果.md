# 3W 1.1.1适配DVAE的四组消融实验配置与结果

整理日期为2026年11月20日。本文依据现有配置、训练记录、测试预测和核验文件，说明当前采用的四组比较。数据集为3W 1.1.1，随机种子为42和2025，主要指标为九类宏平均Precision、Recall和F1。

## 1. 四组实验及主要结果

四组均以已经完成适配和调优的DVAE为基础。新7D由观测压力、温度序列构造，R为基于新7D的经验规则能量辅助分类损失，C为压力—流量—温度条件预测损失。两组含C的实验均将C预测器的权重衰减设为0。

| 编号 | 模型配置 | 接入新7D | 启用R损失 | 启用C损失 | C预测器权重衰减 |
|---|---|---|---|---|---|
| A | 适配DVAE基线 | — | — | — | — |
| B | 适配DVAE＋新7D＋新R | ✓ | ✓ | — | — |
| C | 适配DVAE＋新7D＋新C | ✓ | — | ✓ | 0 |
| D | 适配DVAE＋新7D＋新R＋C | ✓ | ✓ | ✓ | 0 |

下表为测试集结果。每个种子独立计算Macro-P、Macro-R、Macro-F1，再报告两个种子的均值±样本标准差。

| 编号 | 模型配置 | Macro-P | Macro-R | Macro-F1 |
|---|---|---:|---:|---:|
| A | 适配DVAE基线 | 0.852370 ± 0.058865 | 0.869373 ± 0.069681 | 0.857004 ± 0.063406 |
| B | 适配DVAE＋新7D＋新R | **0.942690 ± 0.005335** | 0.906039 ± 0.017061 | 0.919606 ± 0.010340 |
| C | 适配DVAE＋新7D＋新C，C无权重衰减 | 0.941445 ± 0.009093 | 0.889799 ± 0.007005 | 0.907844 ± 0.003692 |
| D | 适配DVAE＋新7D＋新R＋C，C无权重衰减 | 0.942375 ± 0.010048 | **0.918357 ± 0.000121** | **0.928259 ± 0.004193** |

D组的平均Macro-F1最高。相对A、B、C组，D组的平均Macro-F1分别增加0.071255、0.008654、0.020415，约为7.13、0.87、2.04个百分点。表中Precision最高的是B组，Recall最高的是D组。

## 2. 数据、指标与适配后DVAE

| 项目 | 本轮设置 |
|---|---|
| 数据版本 | 3W 1.1.1 |
| 分类任务 | 标签0—8，共9类 |
| 原始输入变量 | P-PDG、P-TPT、T-TPT、P-MON-CKP、T-JUS-CKP、P-JUS-CKGL、QGL |
| 输入窗口长度、步长 | 128、128 |

四组使用同一既有实例级划分和窗口缓存。该划分按实例相关信息分组，具体定义由原划分文件及归一化文件中的split SHA追溯。实验属于当前固定划分上的适配验证。历史测试集已经用于多轮开发性比较，论文或汇报应说明这一背景。

对于每个种子，先分别计算9个类别的P、R、F1，然后对类别取算术平均。种子之间再分别汇总三项指标。Macro-F1由逐类F1平均得到，不能用表中Macro-P与Macro-R的调和平均替代。样本标准差采用分母n−1，本表n=2。

### 2.2 基线结构与训练目标

适配后DVAE采用潜在维数8、隐藏维数64。七维观测与七维原始mask拼接，形成14维编码器输入。对后验均值序列μ进行时间统计池化，得到24维主分类表征。

\[
h=\operatorname{concat}\left(
\operatorname{mean}_t\mu_t,
\operatorname{std}_t\mu_t,
\mu_{T-1}-\mu_0\right)\in\mathbb R^{24}.
\]

标准差采用总体标准差。基线分类器为24→64→9，隐藏层使用ReLU和Dropout，Dropout概率为0.1。

适配后的主要目标为

\[
\mathcal L_{\mathrm{base}}
=0.1\mathcal L_{\mathrm{rec}}
+0.001\mathcal L_{\mathrm{KL}}
+2\mathcal L_{\mathrm{CE}}.
\]

重建项采用标准化观测空间中的固定方差高斯负对数似然，并在真实观测位置上平均。KL项在批次、时间及潜在维度上平均。主分类交叉熵使用训练类频率的平方根逆频率权重，并将权重归一化为均值1。后验和初始潜在变量使用重参数采样，后验及先验标准差截断到[0.02, 5]。

A组直接复用各自种子的P3适配调优最佳检查点。原P3调优配置采用AdamW，学习率3e-4、batch128、最多8轮、patience3、权重衰减1e-5、梯度裁剪5。表中A组按42和2025两个种子重新汇总。

## 3. 新7D的构成与分类接入

新7D在长度128的观测窗口上计算。每一项都使用原始观测mask确定统计值的有效性。

| 维度 | 变量 | 统计量与含义 |
|---|---|---|
| 1 | P-TPT | 末32点有效均值减首32点有效均值，描述压力变化 |
| 2 | P-MON-CKP | 末32点有效均值减首32点有效均值，描述另一压力位置的变化 |
| 3 | T-TPT | 末32点有效均值减首32点有效均值，描述温度变化 |
| 4 | T-JUS-CKP | 末32点有效均值减首32点有效均值，描述另一温度位置的变化 |
| 5 | P-TPT | 相邻且双有效的采样点差分RMS，描述压力波动 |
| 6 | T-TPT | 相邻且双有效的采样点差分RMS，描述温度波动 |
| 7 | P-TPT、P-MON-CKP | 共同有效时刻上的Pearson相关系数，描述压力协同变化 |

首末变化要求两段均有有效观测，差分RMS要求存在相邻双有效点，相关系数要求有效样本及非零方差。统计量无效时，将对应证据置为中性0。

各维统计量使用训练集固定抽样拟合257个分位点，得到经验CDF，进行2F−1变换并中心化。该变换使用训练数据拟合。七维证据随后经过共享可学习正增益和tanh。

\[
\widetilde e_j=\tanh\left(\operatorname{softplus}(a_j)e_j\right).
\]

增益初始化为1。B、C、D组将24维潜在统计表征与7维证据拼接，主分类器为31→64→9。初始化时复制基线分类器原24维输入列、偏置及输出层，新增7维列采用同种子下匹配的随机初始化。

因此，四组中A使用24维分类输入，B、C、D使用31维分类输入。B、C、D同一种子共享相同的主模型与新增7D分类参数初始值。

## 4. 新R与新C的实现

### 4.1 新R——新7D经验规则能量辅助分类损失

R使用可学习线性分类头7→9，对变换后的新7D进行辅助分类。

\[
\mathcal L_R=\operatorname{CE}(W_R\widetilde e+b_R,y).
\]

规则头的初始化依据训练集中各类别的新7D响应原型及共享对角方差。每一维的方差下限为1e-4，类别内缺失统计采用该维训练总体均值回退。随后规则头参数参与学习。R使用普通交叉熵，主分类交叉熵使用类别权重。

这里的“新R”强调与压力/温度新7D的语义适配。其先验属于训练数据导出的类别响应先验。主分类器和R头共享七维证据增益，因此R可通过这些增益影响主分类输入。新7D由固定观测统计得到，R的直接梯度到达规则头和共享增益。C的梯度则通过历史潜在状态到达DVAE编码器，这两条作用路径应分别说明。

### 4.2 新C——掩码条件预测损失及独立零衰减优化

当前四组中的C采用1.1.1掩码条件预测任务，配置如下。

| 项目 | 配置 |
|---|---|
| 历史段 | 前64个采样点 |
| 预测间隔 | lag=4 |
| 预测长度 | 16点 |
| 预测目标位置 | 零基索引68—83，即第69—84个采样点 |
| 压力历史变量 | P-PDG、P-TPT、P-MON-CKP、P-JUS-CKGL |
| 流量目标 | QGL |
| 温度目标 | T-TPT、T-JUS-CKP |
| 历史潜在状态 | 从前64点观测和mask单独编码 |
| 条件预测器隐藏维数 | 64 |
| 流量、温度误差 | 真实观测mask下的高斯NLL |
| 内部流量权重 | 0.005 |
| 内部温度权重 | 1 |
| 外部C损失权重 | 0.001 |
| C预测器学习率 | 3e-4 |
| C预测器权重衰减 | 0 |

压力历史与历史latent参与流量预测。温度预测结合温度历史、压力状态及流量条件信息，并以最后历史温度加残差的方式输出，残差缩放系数为0.1。训练时流量teacher forcing比例为0.15，独立预测诊断时使用0。

QGL历史具有有效观测时，模型启用流量条件通路；缺失时采用压力/温度回退。流量和温度监督只对有效目标计算。原始mask进入DVAE的历史编码，C使用该历史latent。

\[
\mathcal L_C=0.005\mathcal L_Q+\mathcal L_T.
\]

本文件中“新C”的修正重点是为原条件预测器设置独立零权重衰减参数组。具体预测目标采用上表的高斯条件预测任务。C组和D组采用相同的C任务、损失系数及优化设置。

### 4.3 C损失权重与C权重衰减

C损失权重0.001控制辅助预测误差对联合训练的影响。C预测器的weight_decay控制其参数正则化。当前C、D组通过Adam参数组配置主模型及R相关参数衰减1e-5，C预测器参数衰减0。

此前的参数和梯度诊断发现，统一衰减设置下C预测器的部分权重范数收缩到约1e-38，latent扰动对温度预测的影响消失。训练探针中，C的数据梯度与耦合L2梯度存在尺度失衡。零衰减消融用于检验这一机制，修正后预测器参数及latent敏感性恢复。

两种子测试结果也显示了配置依赖性。C单独接入时，有衰减组的平均F1为0.913101，零衰减组为0.907844，变化−0.005257。R+C组合中，原有衰减组为0.889281，零衰减组为0.928259，变化＋0.038978。当前四组使用统一的C零衰减配置，便于比较R与C在同一C优化条件下的单独及组合效果。

## 5. 各组目标函数、初始化与训练预算

\[
\begin{aligned}
\mathcal L_A&=\mathcal L_{\mathrm{base}},\\
\mathcal L_B&=\mathcal L_{\mathrm{base}}+0.0005\mathcal L_R,\\
\mathcal L_C^{\mathrm{group}}&=\mathcal L_{\mathrm{base}}+0.001\mathcal L_C,\\
\mathcal L_D&=\mathcal L_{\mathrm{base}}+0.0005\mathcal L_R+0.001\mathcal L_C.
\end{aligned}
\]

B、C、D组均从对应种子的适配后DVAE检查点建立拼接分类器，再进行联合续训。DVAE编码器、生成部分、主分类器和启用的辅助参数共同优化。

| 项目 | B、C、D组联合训练配置 |
|---|---|
| 优化器 | Adam |
| 主模型与C预测器学习率 | 均为3e-4 |
| Batch size | 32 |
| 主模型及R相关参数衰减 | 1e-5 |
| 启用C时的C预测器参数衰减 | 0 |
| 数据预算 | 全量训练276,108窗口，完整验证61,744窗口 |
| 最大轮数、早停 | 10轮，patience=4 |
| 梯度裁剪 | 全模型范数上限5 |
| 选模指标 | 验证集Macro-F1 |
| 参与选模的检查点 | 已完成训练轮次的检查点，从第1轮起选优 |
| 新7D变换及类别先验 | 使用训练数据拟合，联合阶段读取固定结果 |

A组对应原P3最佳模型，B、C、D包含额外联合训练。它们相对A的差值同时包含新7D接入、续训及相应辅助损失的影响。四组间的模块比较应结合下一节的匹配对照理解。

主诊断推理使用DVAE潜在表征、启用的新7D以及主分类器。R规则头和C条件预测器用于训练监督及辅助诊断。

### 6.2 已有新7D无R/C匹配对照

同一联合训练协议下，还完成了“适配DVAE＋新7D、无R/C”对照。其两种子测试结果为

| 对照配置 | Macro-P | Macro-R | Macro-F1 |

当前四组结果支持以下描述。新7D及联合训练后的各方案平均成绩高于原适配基线；在当前两个种子和固定划分上，R+C零衰减组合取得最高平均F1；C零衰减的效果与R是否共同启用有关。跨种子稳定性仍应结合单种子成绩及标准差报告。
