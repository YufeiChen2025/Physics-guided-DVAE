# 7D Rule Evidence 最终方案实验结果总结

日期：2026-09-16

## 1. 当前主路线

截至 2026-09-16，当前主路线 更新为 **7D rule evidence**。

主线模型为：

```text
DVAE latent representation
+ 7D rule evidence features
+ unified rule-energy auxiliary loss
+ chain prior auxiliary loss
```

分类器输入为：

```text
logits_cls = Classifier(concat(mean_t(z), e_rule_7d))
```

训练总损失为：

```text
L_total =
    L_rec
  + beta * L_KL
  + lambda_cls * CE(logits_cls, y)
  + lambda_chain * L_chain
  + lambda_rule * L_rule_energy
```

当前主线仍启用 `L_rule_energy`：

```text
use_unified_physical_rule = true
use_rule_evidence_features = true
pinn_weight = 0.0005
use_rule_energy_logits = false
```

也就是说，规则证据一方面拼接进分类器输入，另一方面通过较小权重的 `L_rule_energy` 作为辅助监督项参与训练；但规则 logits 不直接融合到最终分类 logits。

## 2. Rule Evidence 从 10D 更新为 7D




经过维度级消融后，当前主线删除了 3 个维度：

```text
deleted = [
  dhsv_drop,
  pck_smooth,
  dp_trend
]
```

因此当前 7D rule evidence 为：

```text
e_rule_7d = [
  water_rise,
  water_smooth,
  dhsv_open_mean,
  pck_drop,
  pck_open_mean,
  dhsv_low_evidence,
  pck_low_evidence
]
```

| 维度 | 含义 |
|---|---|
| `water_rise` | 含水上升趋势 |
| `water_smooth` | 含水序列平滑性/粗糙度 |
| `dhsv_open_mean` | DHSV 平均开度 |
| `pck_drop` | PCK 开度下降趋势 |
| `pck_open_mean` | PCK 平均开度 |
| `dhsv_low_evidence` | DHSV 低开度证据 |
| `pck_low_evidence` | PCK 低开度证据 |

删除原因：

- `dp_trend`：在 medium 单维消融中有噪声嫌疑，full 最优候选也删除该维度；
- `pck_smooth`：与 PCK 边界存在干扰，删除后 full 上 Class 5/8 混淆显著改善；
- `dhsv_drop`：单独删除收益不大，但与 `dp_trend,pck_smooth` 一起删除后 full 指标最优，说明在当前统一 rule loss 下可能产生跨类干扰。

## 5. 当前最终结论

当前推荐主方案为：

```text
7D rule evidence
+ L_rule_energy, lambda_rule = 0.0005
+ chain prior auxiliary loss
+ no rule-logit fusion
+ no direct RE dimension expansion
+ no current boundary loss
```

当前主线结果：

```text
Accuracy = 0.8898
Macro-F1 = 0.9013
Balanced Acc = 0.9165
Class 5 Precision = 0.9787
Class 8 Recall = 0.7980
8->5 = 0
```

与 9.10 版本相比，最重要的变化是：

1. rule evidence 从 10D 更新为 7D；
2. 删除 `dhsv_drop,pck_smooth,dp_trend`；
3. 当前 full 最佳从早期 `Macro-F1=0.8589` 提升到 `0.9013`；
4. Class 8 被 Class 5 吸收的问题已经基本解决；
5. 后续主要研究对象变为 Normal/7/8 边界混淆。

因此，当前阶段论文/主实验线应以 **7D rule evidence 版本** 作为主方案。RE 扩维和 boundary loss 均作为探索性实验记录，不进入主路线。
